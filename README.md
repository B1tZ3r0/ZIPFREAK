## Features
- **AES-256 Encrypted ZIP** creation
- **Multi-mode Cracking Engine**:
  -  Dictionary attacks (with rockyou.txt fallback)
  -  Brute-force (configurable charset)
  -  Smart mask attacks
- Real-time password strength analysis
-  Colorized terminal interface
